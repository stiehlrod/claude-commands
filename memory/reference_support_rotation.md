The support rotation schedule is tracked on Google Calendar:
https://calendar.google.com/calendar/u/0/r/week

**How to apply:** Do not assume the user is on support rotation. The calendar is the source of truth, but it requires authenticated access (can't be fetched via API). If rotation status is unknown, omit support rotation from standup rather than guessing. As of 2026-04-14, user is NOT on support rotation.
