Never post replies to GitHub PR review comments (or any GitHub comments/reviews) without showing the proposed reply text and getting explicit user approval first.

**Why:** User wants to control what gets posted to GitHub on their behalf — auto-posting without confirmation is not acceptable.

**How to apply:** When addressing PR comments, draft the reply text in the conversation and ask "OK to post this?" before calling any GitHub API to submit it.
